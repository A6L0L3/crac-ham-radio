> 把「CRAC 业余无线电台操作证书」的 A / B / C 类考纲与题库，重构成可系统学习、可逐题检索的备考笔记库。

本仓库不做"题库搬运"，而是把**零散题目重构成知识体系**：先按考纲切板块，再把每块拆成「这条规则是什么 → 为什么这么规定 → 怎么记 → 怎么验证学会了」，并在每个板块末尾附**题库逐题索引**，方便按考点回查原题。

## 板块0 · 学习路径和建议

### 0_1 学习路径

1. **先定类别与版本**：确认要考 A / B / C 哪一类，并选定对应考纲版本（2021 或 2025）。
2. **读对应篇的 README 与板块0**：明确考什么、先学什么、怎么学。
3. **按板块推进**：法规 → 呼号 → 频率 → 设备 → 通联 → 电学/天线，每块走「规则 → 原理 → 记忆点 → 验证」。
4. **用题库索引回查**：每板块末的逐题索引用于按考点定位原题，考前速览与精读兼顾。
5. **跨版对照**：若两版都读，以 2025 版为准，2021 版作补充与旧题参照。

### 0_2 使用建议与边界声明

- 内容仅供学习参考，**不替代官方考纲与题库**；报考类别、考试安排、题库版本与合格标准，一律以 CRAC 及当次考试公告为准。
- 本仓库全部文件由公开或原始资料收集而来，并经 AI 工具重新归纳、整理与结构化；整体格式与大纲参考了「庚戊学堂」的学习模块组织方式。题库、考纲与官方文件的著作权归各自权利人所有，本仓库仅对**整理汇编成果**采用 CC BY 4.0（见文末协议）。二创请注明出处，商业使用前请自行确认合规。

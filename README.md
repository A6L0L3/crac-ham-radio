# CRAC 业余无线电台操作证书考试笔记本（**`crac-ham-radio`**）

[![License: CC BY 4.0](https://img.shields.io/badge/License-CC%20BY%204.0-lightgrey.svg)](https://creativecommons.org/licenses/by/4.0/deed.zh)

> 把「CRAC 业余无线电台操作证书」的 A / B / C 类考纲与题库，重构成可系统学习、可逐题检索的备考笔记库。

本仓库不做"题库搬运"，而是把**零散题目重构成知识体系**：先按考纲切板块，再把每块拆成「这条规则是什么 → 为什么这么规定 → 怎么记 → 怎么验证学会了」，并在每个板块末尾附**题库逐题索引**，方便按考点回查原题。

## 📖 分区说明

### 2021 版考纲

对应 2021 版题库（版本 v20211022，约 1237 题），按法规、呼号、频率、设备、通联、电学、天线等模块组织为 11 个板块，覆盖 A / B / C 三类证书的共有与分级考点。

### 2025 版考纲

对应更新后的考纲，按 A / B / C 三类分别标注适用范围，组织为 20 个板块（约 1375 题），重点补充了新技术、新规与分级权限矩阵。

> 两篇的每个板块末尾均设「附录：板块N · 题库逐题索引（题干+正解）」，可按考点快速定位原题；正文与小故事、速查表分列，兼顾精读与考前速览。

## 🧭 笔记体例

每篇笔记自足、格式统一：

```
# 板块0 · 学习路径与备考总纲
## 0_1 小节
## 0_2 小节
# 板块1 · 法规体系与监管职责
## 1_1 ……
## 附录：板块1 · 题库逐题索引（题干+正解）
```

- 板块0 承担「考什么 + 先学什么 + 怎么学」的总控；
- 正文按「规则 → 原理 → 记忆点 → 验证」展开，配 ASCII 图与速查表；
- 每块末尾附**题库逐题索引**，题干与正解并列，便于按考点回查；
- 图示一律用 ASCII 字符画 / 表格 / 缩进文本，不依赖外链图片。
